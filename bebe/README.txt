=====================================================
حزمة صفحة الهبوط الكاملة: وسادة منع تسطح الراس الطفل
=====================================================

محتويات هذا الملف المجمع:
1. index.html:
   صفحة الهبوط الكاملة جاهزة للنشر، مرتبطة بمجلد الصور ومدمج بها بطاقة الدفع عند الاستلام (COD) مع حساب التوصيل والتتبع المباشر.

2. images/:
   مجلد يحتوي على كافة صور صفحة الهبوط بجودة عالية وصيغة WebP سريعة.

3. google_sheet_orders_script.js:
   ملف كود Google Apps Script الجاهز لربط استقبال الطلبات وتخزينها تلقائياً وفورياً في جدول Google Sheets مجاناً.
   طريقة الاستخدام: افتح جدول Google Sheet جديد -> Extensions -> Apps Script -> الصق محتوى هذا الملف -> Deploy -> Web app.

4. delivery_company.json:
   بيانات شركة التوصيل (ZR Express) متضمنة خيارات التوصيل للمنزل أو المكتب والأسعار وحقول الطلب.

5. project_data.json:
   البيانات البرمجية الكاملة للمشروع لاستيرادها أو إدارتها برمجياً في أي وقت.

طريقة الاستخدام والنشر:
- فك ضغط هذا الملف على جهازك.
- ارفع ملف index.html ومجلد images/ إلى أي استضافة أو خادم تريده (cPanel, Netlify, Vercel, Hostinger, Shopify, etc.).
- ستعمل صفحة الهبوط مباشرة وبسرعة فائقة.
